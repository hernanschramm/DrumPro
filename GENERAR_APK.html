Genera tu APK para Android en minutos

⚡ INICIO RÁPIDO

Un solo comando para generar tu APK

chmod +x generar-apk.sh && ./generar-apk.sh

Tiempo estimado: 3-5 minutos

1

Requisitos

Antes de empezar, necesitas:

  • Node.js 18+
  • Android Studio
  • Java JDK 17
2

Ejecutar Script

Abre la terminal en la carpeta del proyecto y ejecuta:

./generar-apk.sh
3

Obtener APK

El script generará automáticamente:

DrumProAcademy.apk
4

Instalar

Transfiere el APK a tu Android:

adb install DrumProAcademy.apk

⚠️ Importante

Este es un proyecto web (React/Vite) que se empaqueta como app Android usando Capacitor. No puedo generar el APK directamente desde este entorno, pero el script generar-apk.sh hace todo el trabajo automáticamente en tu máquina local.

✅ ¿Qué incluye la app?

  • Sistema completo de autenticación (3 roles)
  • Gestión de clases con calendario
  • Sistema de tareas con grabación de video
  • Evaluaciones con rúbricas
  • Biblioteca de 40 rudimentos y 22 grooves
  • Metrónomo profesional
  • Videollamadas integradas
  • Multitrack player con detección de BPM
  • Piano roll para análisis de notas
  • Grabación de video para redes sociales

🔧 Troubleshooting

Problema: "SDK location not found"

Solución:

echo "sdk.dir=$HOME/Library/Android/sdk" > android/local.properties

Problema: "App se cierra al abrir"

Solución:

npm run build && npx cap sync android
